# Exercícios Python - 6A

Repositório criado para armazenar os exercícios de Python da disciplina de IA.

## Arquivos

- **Exercícios_Python_GustavoSprangoski6A.ipynb** — notebook do Google Colab com todos os exercícios resolvidos e comentados

## Sobre os exercícios

São 50 exercícios, desde o básico até tópicos um pouco mais avançados:

- Entrada e saída de dados
- Condicionais e loops
- Listas, dicionários e strings
- Funções e recursão
- Algoritmos de ordenação (Bubble Sort, Insertion Sort)
- Busca binária
- Jogos simples (forca, adivinhação, jogo da velha)
- Validação de CPF
- Cifra de César
- Geração de gráficos com matplotlib

## Como abrir

Basta fazer o upload do arquivo `.ipynb` no [Google Colab](https://colab.research.google.com/) e executar as células.
